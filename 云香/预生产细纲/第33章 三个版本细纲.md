## 版本A：画舫暗流（推荐）

**基调**：金榜题名的高光时刻，暗流涌动的政治初体验

### 核心情节点（7个）

**情节点1** [沈砚之 POV]

- **人物状态**：放榜日清晨，聚英客栈
- **核心事件**：张榜，沈砚之中**经魁**（举人第五名）
- **冲突**：榜单前水泄不通，周鹤鸣挤进去看榜
- **反转**：周鹤鸣回头大喊——"沈兄！第五名！经魁！"
- **钩子**：沈砚之愣在原地，耳边炸开恭喜声

**情节点2** [沈砚之 POV]

- **人物状态**：同日下午，收到织造府请柬
- **核心事件**：曹文彬宴请中举前五名，秦淮河画舫
- **冲突**：沈砚之不想去这种应酬场合，但周鹤鸣说"必须去"
- **反转**：请柬上写着"江宁织造曹文彬敬备薄酒，恭贺新科举人"
- **钩子**：沈砚之换上唯一一件体面的青衫赴宴

**情节点3** [画舫全景]

- **人物状态**：华灯初上，画舫停泊秦淮河畔
- **核心事件**：通传"和老板到"，大人物起身相迎，举人们跟着起身
- **冲突**：众人纷纷猜测——富商打扮却受官员尊敬，此人绝不简单
- **反转**：曹文彬引见——"这位是京城来的丝绸大商，和老板"
- **钩子**：和琳身后跟着一个身材瘦小、白净的小厮（舒婉扮的）

**情节点4** [舒婉 POV/隐藏]

- **人物状态**：扮小厮，垂手立在和琳身后
- **核心事件**：和琳一眼认出——亲人天天见，身形举止瞒不过他
- **冲突**：和琳借故低声："你怎么跟来了？"舒婉低头不答
- **反转**：和琳冷脸训斥——"不许出声，不许走动，就站在这儿"
- **钩子**：舒婉心里一紧，但目光忍不住瞟向席间——她认出了他，鸡鸣寺银杏树下那个人

**情节点5** [沈砚之 POV]

- **人物状态**：画舫内，席中诗词歌赋，以丝绸为题
- **核心事件**：轮到沈砚之，他赋诗一首，诗中展露对丝绸的独到理解
- **冲突**：诗中提到"缫丝分粗细，煮茧辨温凉"——不是书生口吻，是内行话
- **反转**：曹文彬目光一凝，放下酒杯——"沈举人对丝绸有研究？"
- **钩子**：沈砚之如实答："家嫂在苏州经营丝局，略知一二。"曹文彬笑容更深

**情节点6** [和琳 POV]

- **人物状态**：席间观察，注意到曹文彬对沈砚之的兴趣
- **核心事件**：和琳借敬酒之机，与沈砚之寒暄
- **冲突**：和琳问苏州丝绸行情，沈砚之谨慎应对
- **反转**：和琳笑道——"沈举人有空来京城，咱们再细聊"
- **钩子**：舒婉站在和琳身后，把每一句话都记在心里

**情节点7** [次日鹿鸣宴 POV]

- **人物状态**：鹿鸣宴上，新科举人拜谢主考官
- **核心事件**：刘墉逐一召见前五名，对沈砚之时间最长
- **冲突**：刘墉举杯——"你的文章我看了，'不当私于一族一姓'——但愿十年后，你还能记得这句话"
- **反转**：沈砚之跪答——"学生愚钝，请大人教诲"
- **钩子**：刘墉看着他，半晌，点头——师徒关系，自此缔结

### 核心台词（7句）

1. **周鹤鸣**（看榜时）："沈兄！第五名！经魁！"
2. **通传**："和老板到——"
3. **和琳**（训斥舒婉）："不许出声，不许走动，就站在这儿"
4. **沈砚之**（赋诗）："缫丝分粗细，煮茧辨温凉"
5. **曹文彬**："沈举人对丝绸有研究？"
6. **沈砚之**："家嫂在苏州经营丝局，略知一二"
7. **刘墉**（鹿鸣宴）："但愿十年后，你还能记得这句话"

### 情绪曲线

[震惊] → [应酬] → [好奇] → [被审视] → [试探] → [警告] → [缔结]

### 主题落点

金榜题名不是终点，而是进入更复杂棋局的起点。画舫上每个人都在演戏——曹文彬在物色棋子，和琳在摸底对手，舒婉在暗处看着心上人，而沈砚之还不知道，自己已经被几方势力同时盯上。

### 四字节奏

[张榜经魁] → [赴宴画舫] → [和老板到] → [不许走动] → [丝绸入诗] → [曹公试探] → [鹿鸣受教]

## 版本B：信息不对称

**基调**：她知道他的一切，他却连她是谁都不知道

### 核心情节点（6个）

**情节点1** [沈砚之 POV]

- **人物状态**：榜单前
- **核心事件**：中经魁
- **反转**：周鹤鸣比他还激动
- **钩子**：沈砚之第一反应不是高兴，而是"苏锦婳知道了没有"

**情节点2** [沈砚之 POV]

- **人物状态**：画舫宴
- **核心事件**："和老板到"，众人起身
- **冲突**：官员恭敬，举人猜测，气氛微妙
- **反转**：曹文彬介绍和琳，沈砚之觉得此人不像普通商人
- **钩子**：和琳身后的小厮一直垂着眼，但沈砚之总觉得有人在看自己

**情节点3** [舒婉 POV/隐藏]

- **人物状态**：扮小厮，被和琳训斥后僵立不动
- **核心事件**：她认出了他——鸡鸣寺银杏树下捡丝巾的人
- **冲突**：她想看，不敢看；想听，不敢出声
- **反转**：和琳借转身之机，低声："你再敢乱动，我立刻送你回京"
- **钩子**：舒婉咬住嘴唇，眼睛却粘在那个青衫举子身上

**情节点4** [沈砚之 POV]

- **人物状态**：席中赋诗，以丝绸为题
- **核心事件**：诗中提到缫丝、煮茧、分等——内行话
- **冲突**：曹文彬目光一凝，追问
- **反转**：沈砚之答"家嫂经营丝局"，曹文彬笑："锦云丝局，我知道"
- **钩子**：沈砚之心中一凛——曹文彬知道锦云丝局

**情节点5** [舒婉 POV/隐藏]

- **人物状态**：僵立在和琳身后，把每一句话刻进心里
- **核心事件**：她知道了——他叫沈砚之，苏州人，家中开了锦云丝局
- **冲突**：她想：原来他不是普通书生，他懂丝绸
- **反转**：又一想：他诗里写的"煮茧辨温凉"——那是养蚕人才知道的细节
- **钩子**：她不知道，她记住的每一句诗，都是未来感情纠葛的起点

**情节点6** [鹿鸣宴]

- **人物状态**：刘墉逐一召见前五名
- **核心事件**：对沈砚之时间最长
- **冲突**：刘墉说"但愿十年后你还记得这句话"
- **反转**：沈砚之答"学生愿意试着折一折"
- **钩子**：刘墉罕见地笑了——这个门生，他收定了

### 核心台词（6句）

1. **沈砚之**（心里想）："苏锦婳知道了没有"
2. **通传**："和老板到——"
3. **和琳**（训斥）："你再敢乱动，我立刻送你回京"
4. **沈砚之**（赋诗）："煮茧辨温凉，分等看丝光"
5. **曹文彬**："锦云丝局，我知道"
6. **刘墉**："但愿十年后你还记得这句话"

### 情绪曲线

（沈砚之）茫然 → 警惕 → 应对 → 领悟
（舒婉）紧张 → 偷看 → 被发现 → 不甘 → 铭记

### 主题落点

信息不对称是权力场的常态。舒婉掌握的信息比沈砚之多——她知道他是谁，他不知道她是谁。这种不对等，将在未来很长一段时间内定义他们的关系。

### 四字节奏

[中榜念嫂] → [和老板到] → [不许乱动] → [丝绸入诗] → [曹公试探] → [恩师收徒]

## 版本C：高光与阴影

**基调**：金榜题名的表面风光下，是各方势力的暗中角力

### 核心情节点（5个）

**情节点1** [放榜]

- 沈砚之中经魁
- 其他四名举人身份各异：富家子、官宦子弟、寒门、旗人
- 周鹤鸣中第八名

**情节点2** [画舫宴]

- 通传"和老板到"，大人物起身，举人跟着起身
- 和琳以富商打扮出场，众人纷纷猜测其身份
- 身后跟着小厮（舒婉），被和琳一眼认出，训斥后禁止走动

**情节点3** [诗词试探]

- 席间以丝绸为题赋诗
- 沈砚之诗中展露内行知识
- 曹文彬追问，才知家中开了锦云丝局

**情节点4** [舱外暗流]

- 和琳借敬酒之机与沈砚之谈苏州丝绸
- 舒婉站在身后，把每一句话刻进心里
- 她知道了他叫沈砚之，苏州人，懂丝绸

**情节点5** [鹿鸣宴]

- 刘墉逐一召见前五名
- 对沈砚之说："你的文章有骨，但愿十年后骨还在"
- 沈砚之答："学生愿意试着保一保"
- 刘墉点头——师徒关系，缔结

### 核心台词（5句）

1. **周鹤鸣**："沈兄！经魁！"
2. **通传**："和老板到——"
3. **和琳**（训斥舒婉）："不许出声，不许走动"
4. **曹文彬**："锦云丝局，我知道"
5. **刘墉**："但愿十年后骨还在"

### 情绪曲线

[狂喜] → [应酬] → [警惕] → [受教] → [立志]

### 主题落点

金榜题名是入场券，不是护身符。刘墉的警告、曹文彬的试探、和琳的审视，都在告诉沈砚之：从这一刻起，他不再只是一个读书人，而是棋盘上的子。

### 四字节奏

[金榜题名] → [和老板到] → [不许走动] → [丝绸入诗] → [鹿鸣受教]

## 备注

- **舒婉身份保密**：沈砚之此时完全不知道舒婉是谁，只知道鸡鸣寺有个"婉姓女子"
- **和琳身份**：以"丝绸商人"身份出场，真实身份暂不揭露
- **曹文彬的目的**：在物色有潜力的汉臣，为内务府织造业务寻找政治代理人
- **刘墉的警告**：不是打压，是保护——让沈砚之提前知道官场风险
- **沈砚之的觉醒**：从这一天起，他意识到自己不再只是"读书人"，而是被多方势力注视的"官场新秀"
- **舒婉的单向认知**：这是全书感情线最关键的伏笔——她在暗处看着他，他在明处一无所知
