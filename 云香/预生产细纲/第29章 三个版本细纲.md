## 版本A：石青出手

**基调**：江湖快意恩仇，乞丐露峥嵘，一战定主仆名分

### 核心情节点（5个）

**情节点1** [石青 POV]

**石青线**
- 人物状态：蹲守锦云丝局门外第二日清晨，昨夜想了一夜怎么开口
- 核心事件：麻六带着三个无赖踹开丝局大门，以"收摊位费"为由索要银子，扬言"无钱就拿丝抵"
- 冲突：石青在暗处观察，判断这是清河镇街痞收保护费的老把戏，正犹豫要不要管
- 反转：麻六见苏锦婳独自一人，油腻腻地笑着伸手要摸她的脸
- 伏笔：为第30章石青身世回忆埋线
- 钩子：石青从墙根站起来，拍了拍膝盖上的灰，一步一步走向那四个无赖

**情节点2** [苏锦婳 POV]

**苏锦婳线**
- 人物状态：正在柜台后理账，陈四去后院搬货，独自面对四个无赖
- 核心事件：麻六伸手要摸她的脸，苏锦婳后退一步，手摸到了柜台下的剪子
- 冲突：她知道自己打不过四个人，但不能让这人碰到自己
- 反转：门口传来一声闷哼——麻六的胳膊被卸了下来
- 伏笔：为石青真实身份（镖师）埋线
- 钩子：石青的声音从门口传来，低沉，像砂石磨过铁："手干净点。"

**情节点3** [石青 POV]

**石青线**
- 人物状态：一对一的情况下卸了麻六胳膊，动作干净利落，是擒拿里的"小缠丝"
- 核心事件：剩下三个无赖抄起棍子一拥而上，石青侧身让过第一棍，抬腿踢中来人膝盖；顺手抄起门闩，以一敌三，三招之内全部放倒
- 冲突：四个无赖躺在地上哀嚎，麻六捂着脱臼的肩膀，大喊"有种报上名来！"
- 反转：石青没有报名字，只是把他的另一只胳膊也卸了，说"以后再来，断两条"
- 伏笔：石青为何流落至此的完整身世（第30章回忆）
- 钩子：石青把门闩放回原位，拍了拍手，看向苏锦婳："掌柜的，借一步说话。"

**情节点4** [苏锦婳 POV]

**苏锦婳线**
- 人物状态：站在柜台后，手里还攥着那把剪子，看着门口这个乞丐模样的男人
- 核心事件：石青把四个无赖拖出巷口，回来后拱手："掌柜的，借一步说话。"苏锦婳点头，带他进了后院
- 冲突：石青开口第一句话是"我叫石青"，第二句话是"我认识一个叫刘长贵的人"
- 反转：苏锦婳手中的剪子彻底掉在地上——她以为舅舅早就死在荆州水灾里了
- 伏笔：舅舅的完整遭遇和石青的来历（第30章石青口述身世）
- 钩子：石青从怀里摸出一个布包，里面是一枚旧银镯："他临走前交给我的，说等他死后转交给你。"

**情节点5** [苏锦婳+石青 双 POV]

**苏锦婳线**
- 人物状态：在后院单独面对石青，听他讲述来龙去脉
- 核心事件：石青讲述——刘长贵被镖局收留，镖局得罪权贵被灭门，刘长贵舍命救他，临终托他来看苏锦婳的日子过得好不好
- 冲突：苏锦婳问"他什么时候死的"，石青说"三年前"
- 反转：苏锦婳才知道，舅舅在荆州水灾之后还活了十几年，最后死在一个叫石家镖局的地方
- 伏笔：第30章石青身世完整揭露
- 钩子：石青说完，单膝跪下："少奶奶，石青奉命护你周全。你若不弃，石青此生不走。"

**沈砚之线（平行插入）**
- 人物状态：抵达江宁，入住贡院旁聚英客栈，三人一间
- 核心事件：同住秀才知道今年主考官是刘墉，"铁面御史"之名让周鹤鸣等有背景的考生都心里打鼓
- 钩子：沈砚之记下这个名字——刘墉，铁面御史，与织造局有没有关系？

### 核心台词（4句）

1. **麻六**（油腻腻地）："小娘子自己开门做生意，怎么不让兄弟们照顾照顾？"（引发冲突）
2. **石青**（低沉）："手干净点。"（出手前警告，简短有力）
3. **苏锦婳**（声音发颤）："他……他什么时候死的？"（听到舅舅死讯）
4. **石青**（单膝跪地）："少奶奶，石青奉命护你周全。你若不弃，石青此生不走。"（正式入伙宣言）

### 情绪曲线
惊惧 → 愤怒 → 震撼 → 感动 → 坚定

### 主题落点
主仆之义：刘长贵虽死，他的托付穿越十年抵达；石青用一双手还了故人的债

### 四字节奏
[风起萍末] → [拳脚相见] → [后院独话] → [单膝认主]

## 版本B：沈砚之江宁行

**基调**：寒门举子的京城初印象，政治嗅觉在烟火气中觉醒

### 核心情节点（5个）

**情节点1** [沈砚之 POV]

**沈砚之线**
- 人物状态：抵达江宁城外，走水路转旱路，身上青衫已经三夜没换
- 核心事件：过城门遇兵丁盘查，亮出秀才腰牌和府学文书，兵丁多看了两眼——穷酸秀才，身边连个小厮都没有
- 冲突：同船几个秀才议论纷纷，说"今年主考是刘墉，那个铁面御史"
- 反转：刘墉之名让有门路的考生都心里发毛——此人六亲不认，风闻极严
- 伏笔：刘墉与沈砚之日后在山东的师生关系（第131章起）
- 钩子：沈砚之默默记下：主考刘墉，铁面御史，不走后门

**情节点2** [沈砚之 POV]

**沈砚之线**
- 人物状态：入城找客栈，贡院周边客栈满员，最后在深巷找到"聚英客栈"，三人一间
- 核心事件：同住两人——周鹤鸣，常州人，家境殷实，带两小厮；孙海文，松江人，沉默寡言，书箱里全是经义范文
- 冲突：周鹤鸣席间叹气："今年刘墉主考，我爹托了多少人情都没用。"另一个秀才说"那就只能走织造局的路子了"
- 反转：沈砚之听到"织造局"，心里一动——苏州也有织造局，苏锦婳的丝正往那边销
- 伏笔：织造局与曹文彬的关系（第31章引出）
- 钩子：夜深了，沈砚之躺在窗边，拿出苏锦婳塞给他的一两银子，在月光下看了很久

**情节点3** [沈砚之 POV]

**沈砚之线**
- 人物状态：次日清晨，在贡院外查看考场位置
- 核心事件：江宁城的繁华超出想象——秦淮河灯船已经开始招揽客人，织造局大门气派，三个沈家村那么大
- 冲突：沈砚之在织造局门前站了一会儿，被门子挥手赶走："走走走，这里是你能看的吗？"
- 反转：沈砚之没争辩，只是记住了这个地方——织造局，苏州那边也有
- 伏笔：第31章曹文彬在苏州的画舫上
- 钩子：他转身离开时，听见门子在里面打电话："曹大人今儿个在画舫上请客……"

**情节点4** [苏锦婳 POV]

**苏锦婳线**
- 人物状态：锦云丝局清晨开门，陈四去后院
- 核心事件：麻六带四个无赖踹门进来，说"这条街的规矩，新开张的铺子都要意思意思"
- 冲突：苏锦婳知道硬抗没有好下场，货还在后院
- 反转：她刚要开口，门口传来一声闷响
- 钩子：苏锦婳后来才知道，沈砚之此刻正在江宁贡院外看考场，而她差一点被麻六调戏

**情节点5** [苏锦婳+石青 双线]

**苏锦婳线**
- 人物状态：看着石青把四个无赖全部放倒
- 核心事件：石青拖完无赖后，拱手说"借一步说话"，苏锦婳带他进了后院
- 冲突：石青说出刘长贵的名字，苏锦婳的剪子掉在地上
- 反转：石青拿出那枚旧银镯，说是刘长贵临死前留给她的
- 伏笔：石青身世完整揭露（第30章）
- 钩子：石青说完，单膝跪下："少奶奶，石青奉命护你周全。"

**沈砚之线**
- 人物状态：夜深，客栈窗边
- 核心事件：拿出那一两银子看了一会儿，想起苏锦婳说的"不急着找吴掌柜"
- 冲突：忽然明白了什么——刘墉主考，织造局在苏州，曹文彬在苏州，锦婳的丝也往苏州销
- 钩子：他要把这个关系网在心里织起来，等回去告诉她

### 核心台词（4句）

1. **周鹤鸣**（叹气）："今年刘墉主考，我爹托了多少人情都没用。"（触发沈砚之警觉）
2. **某秀才**（神秘地）："那就只能走织造局的路子了。"（引出织造局线索）
3. **苏锦婳**（声音发抖）："他……他什么时候死的？"（听到舅舅死讯）
4. **石青**（平淡地）："他临走前说，婳婳的日子过得好不好，他放心不下。"（转述遗言）

### 情绪曲线
新奇 → 压抑 → 警觉 → 担忧 → 释然

### 主题落点
寒门的政治嗅觉：沈砚之在江宁的每一眼看的不只是繁华，而是权力版图和利益关系网

### 四字节奏
[舟车入宁] → [客栈识人] → [织造门前] → [故人托付]

## 版本C：双线交织

**基调**：同一轮月亮下，他在江宁看考场，她在清河收义士

### 核心情节点（6个）

**情节点1** [平行蒙太奇]

**沈砚之线**：清晨入江宁城，过城门盘查，入住聚英客栈三人间，窗外是秦淮河灯影

**苏锦婳线**：清晨开门，注意到石青还蹲在老地方，但今天没缩着——脊背挺直，眼睛跟着丝局门口转

**情节点2** [平行蒙太奇]

**沈砚之线**：在贡院外看考场，遇到周鹤鸣，听其透露主考官是刘墉，"铁面御史"让所有人心里打鼓

**苏锦婳线**：陈四去后院，麻六等四名无赖踹门进来，苏锦婳退到柜台后摸剪刀

**情节点3** [沈砚之为主视角]

**沈砚之线**
- 人物状态：贡院外查完考场，去织造局门前转了一圈，被门子赶走
- 核心事件：听到门子说"曹大人在画舫上请客"，记住了"画舫"这个地点
- 冲突：沈砚之目前不知道画舫意味着什么，但他记住了
- 反转：周鹤鸣在客栈说"走织造局的路子"，沈砚之把刘墉、曹文彬、织造局、苏州联系到了一起
- 伏笔：第31章曹文彬出场
- 钩子：他想起苏锦婳临走前说的"不急着找吴掌柜"，忽然明白了什么

**情节点4** [苏锦婳为主视角]

**苏锦婳线**
- 人物状态：被麻六围困，无路可退
- 核心事件：麻六伸手要摸她的脸，苏锦婳握紧剪刀——门口传来一声闷响
- 冲突：她以为会看到陈四冲进来，结果是一个蓬头垢面的男人，一拳卸了麻六的胳膊
- 反转：石青以一敌三，三招放倒，动作干净利落——这不是普通乞丐
- 伏笔：镖师身份
- 钩子：石青放倒最后一人，转过身看向她，平静地说："掌柜的，借一步说话。"

**情节点5** [苏锦婳 POV]

**苏锦婳线**
- 人物状态：带石青进了后院，两人相对而立
- 核心事件：石青开口："我叫石青。我认识一个叫刘长贵的人。"
- 冲突：苏锦婳以为舅舅死在荆州水灾里，石青说她还活了十几年
- 反转：石青拿出那枚旧银镯，说"他临走前让我转交给你"
- 伏笔：石青身世和镖局覆灭（第30章）
- 钩子：石青说完，单膝跪地："少奶奶，石青奉命护你周全，此生不走。"

**情节点6** [双线收束]

**沈砚之线**：夜深了，沈砚之躺在客栈窗边，拿出那一两银子在月光下看。想起刘墉、织造局、苏州、锦婳的丝——这张网，得等回去跟她说说

**苏锦婳线**：苏锦婳站在后院，看着石青消失在夜色里。月光照在院子里，她低头看着手里那枚旧银镯，泪流满面

### 核心台词（5句）

1. **周鹤鸣**（叹气）："今年刘墉主考，我爹托了多少人情都没用。"（引发沈砚之警觉）
2. **门子**（傲慢）："走走走，这里是你能看的吗？"（触发沈砚之记录地点）
3. **苏锦婳**（警觉）："你……你是谁？"（对石青）
4. **石青**（平静）："我叫石青。认识一个叫刘长贵的人。"（引出核心）
5. **石青**（单膝跪）："少奶奶，石青此生不走。"（入伙宣言）

### 情绪曲线
（沈砚之）新奇 → 压抑 → 警觉 → 思念
（苏锦婳）平静 → 惊惧 → 震撼 → 感动

### 主题落点
两人在同一轮月光下各自生长——他在江宁织一张政治的情报网，她在清河收一个以命相报的死士。两条线各自延伸，却在最高层面上指向同一个方向：他回不去时，她身边有人护着；她织的网，最终会和他的网交织在一起。
