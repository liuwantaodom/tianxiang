## 版本A：高光与落差（推荐）

**基调**：官方认可的高光时刻，与民间追捧的阵仗形成身份剧变的双重冲击

### 核心情节点（7个）

**情节点1** [鹿鸣宴全景]

- **人物状态**：八月二十八清晨，江宁官署
- **核心事件**：新科举人拜谢座师，行门生礼
- **冲突**：其他举人依次上前，刘墉对每个人只说了两三句
- **反转**：轮到沈砚之，刘墉多看了他一眼，说了句"你留下"
- **钩子**：其他举人退下，沈砚之单独站在刘墉面前

**情节点2** [刘墉提点]

- **人物状态**：官署侧厅，只有师徒二人
- **核心事件**：刘墉放下茶杯，看着沈砚之
- **冲突**：刘墉说"你是我取中的人，骨头硬我看在眼里。但在这朝堂上，骨头太硬的人折得也快"
- **反转**：沈砚之跪答"学生谨记座师教诲"；刘墉又说"我不指望你给我争脸，只指望你活长些"
- **钩子**：刘墉递过一本手抄册子——"有空看看，里面是人名"（官场人脉簿）

**情节点3** [骑官马归乡]

- **人物状态**：鹿鸣宴后，沈砚之不等吏部铨选，即刻回乡
- **核心事件**：官府配给高头大马一匹，举人公服一套
- **冲突**：沈砚之不会骑马，周鹤鸣扶他上去
- **反转**：坐在马背上，视野高了，路人的目光也变了
- **钩子**：马蹄声哒哒，向着苏州方向

**情节点4** [路过老槐树]

- **人物状态**：官道旁，村口那棵老槐树下
- **核心事件**：马匹放慢脚步
- **冲突**：沈砚之想起三个月前——穿着旧袍子，揣着仅有的盘缠，步行从这里去江宁
- **反转**：那时路人看他是个穷书生；现在路人看他是个举人老爷
- **钩子**：他拉了拉缰绳，没有停，只是多看了一眼

**情节点5** [苏锦婳收喜报]

- **人物状态**：清河镇锦云丝局后院，苏锦婳正指导工人缫丝
- **核心事件**：前厅传来喧哗，报录的高声唱名
- **冲突**：苏锦婳擦了擦手走出去；报录的举着红帖"捷报：贵府沈砚之老爷，高中乾隆三十六年江南乡试第三名经魁"
- **反转**：苏锦婳接过喜报，手指微颤——不是激动，是警觉
- **钩子**：她心里算了一笔账：中举了，沈老栓的筹码更重了

**情节点6** [沈家村阵仗]

- **人物状态**：沈砚之骑马路入村口
- **核心事件**：知县设宴、族人挂红灯笼、乡绅排队送礼送钱
- **冲突**：王翠娥穿着最好的衣裳在村口炫耀；沈明之躲在人群后不敢上前；郑冬花抱着孩子冷笑
- **反转**：沈砚之下马，被族人簇拥着往家走，每一步都有人拱手道喜
- **钩子**：他回头看了眼那匹马——官府配的，三年后若不中进士，是要还回去的

**情节点7** [沈家忙乱]

- **人物状态**：沈家堂屋，门庭若市
- **核心事件**：送礼的乡绅排成队，王翠娥忙着收礼记账
- **冲突**：沈老栓坐在堂屋正中，烟杆敲了敲地面
- **反转**：他没有说话，只是看着这一切——儿子中举了，沈家的筹码够了
- **钩子**：沈砚之进门，沈老栓抬眼："老三，回来了。"（收编的话，留到明天说）

### 核心台词（7句）

1. **刘墉**："你是我取中的人，骨头硬我看在眼里。但在这朝堂上，骨头太硬的人折得也快。"
2. **刘墉**："我不指望你给我争脸，只指望你活长些。"
3. **沈砚之**："学生谨记座师教诲。"
4. **沈砚之**（路过老槐树，心里想）："三个月前，我也是从这里走的。"
5. **报录的**："捷报：贵府沈砚之老爷，高中乾隆三十六年江南乡试第三名经魁！"
6. **王翠娥**（对邻居）："我儿子是举人！经魁！"
7. **沈老栓**（烟杆敲地）："老三，回来了。"

### 情绪曲线

[庄重] → [警醒] → [新奇] → [恍惚] → [警觉] → [喧嚣] → [暗流]

### 主题落点

中举是身份的分水岭，但不是命运的护身符。刘墉的警告、沈老栓的沉默、苏锦婳的警觉，都在提醒沈砚之：表面的风光越盛，底下的算计越深。

### 四字节奏

[座师提点] → [跪受教诲] → [官马归乡] → [槐树回首] → [后院收喜] → [村口阵仗] → [堂屋暗流]

## 版本B：双重奏

**基调**：官方的高光与民间的追捧，两重身份剧变同时冲击

### 核心情节点（6个）

**情节点1** [鹿鸣宴]

- 新科举人拜谢座师
- 刘墉对沈砚之时间最长
- 留下一句"活长些"

**情节点2** [归途]

- 骑官府配马
- 穿举人公服
- 不会骑马，周鹤鸣扶着

**情节点3** [老槐树]

- 路过村口
- 想起去时穷途
- 现在路人目光变了

**情节点4** [苏锦婳]

- 后院收到喜报
- 表面镇定
- 内心警觉：沈老栓要动了

**情节点5** [阵仗]

- 知县设宴
- 族人挂灯笼
- 乡绅送礼
- 王翠娥炫耀

**情节点6** [沈家]

- 门庭若市
- 沈老栓敲烟杆
- 不说话——明天再说

### 核心台词（6句）

1. **刘墉**："骨头太硬的人折得也快。"
2. **沈砚之**（心里想）："三个月前……"
3. **报录的**："高中经魁！"
4. **苏锦婳**（心里想）："沈老栓要动了。"
5. **王翠娥**："我儿子是举人！"
6. **沈老栓**（烟杆敲地）："老三，回来了。"

### 情绪曲线

（沈砚之）庄严 → 恍惚 → 喧嚣
（苏锦婳）警觉 → 冷静

### 主题落点

身份的改变是瞬间的，但人心的算计是永恒的。沈砚之从书生变成举人，但他在沈家的位置，从"被吸血的读书仔"变成了"最有价值的筹码"。

### 四字节奏

[座师教诲] → [官马启程] → [槐树回首] → [后院喜报] → [村口阵仗] → [堂屋沉默]

## 备注

- **刘墉的提点**：不是打压，是保护——让沈砚之提前知道官场风险，为后续齐河知县阶段遭攻击做铺垫
- **人脉簿**：刘墉递的手抄册子，里面是他多年积累的官场人脉，沈砚之将来会用到
- **官府配马**：举人待遇，但三年后若不中进士需归还，暗示沈砚之必须继续考进士
- **沈老栓的沉默**：本章只到"烟杆敲地"为止，收编的话留到第35章，给读者悬念
- **苏锦婳的警觉**：收到喜报第一反应不是高兴，是算沈老栓会怎么动——体现她的政治嗅觉
- **王翠娥的炫耀**：从"骂老三吃闲饭"到"我儿子是举人"——势利眼的极致表现
