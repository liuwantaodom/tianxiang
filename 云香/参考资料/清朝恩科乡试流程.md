# 清朝恩科乡试流程（小说参考资料）

> 本文档用于《天香》小说创作参考，涵盖恩科制度、乡试流程、考场规则等历史细节

---

## 一、恩科制度

### 1.1 什么是恩科？

恩科是清朝科举制度中"正科"之外的临时加科，因皇帝登基、万寿（生日）等庆典而特诏开科。

| 类型 | 触发条件 | 首次出现 |
|------|----------|----------|
| **万寿恩科** | 皇帝生日（万寿节） | 康熙五十二年（1713年）康熙帝60万寿 |
| **登极恩科** | 新帝即位 | 雍正元年（1723年） |
| **皇太后万寿恩科** | 皇太后生日 | 乾隆十六年（1751年）皇太后60万寿 |

### 1.2 恩科与正科的关系

- **恩正并行**：恩科与正科同年举行，两科同时开考
- **移正就恩**：推迟正科，优先举行恩科
- 本小说设定：乾隆六旬万寿加开恩科，沈砚之参加的是恩科乡试

## 二、乡试时间安排

### 2.1 考试周期

| 项目 | 时间 |
|------|------|
| **正科** | 子、午、卯、酉年（三年一科）八月 |
| **恩科** | 庆典之年，日期另行通知 |
| **三场** | 第一场：八月初九；第二场：八月十二；第三场：八月十五 |
| **入场** | 每场提前一天寅时（凌晨3-5点）点名入场 |
| **出场** | 每场考完后一天放出 |
| **放榜** | 多在寅日或辰日，又称"龙虎榜"、"桂榜"（桂花盛开时节） |

### 2.2 恩科具体时间（乾隆朝）

```
八月初六日：考官入闱（入贡院）
八月初八日：入帘上马宴（内外帘官赴宴）
八月初九日：第一场
八月十二日：第二场
八月十五日：第三场
八月（大约中下旬）：放榜
```

## 三、考场规则

### 3.1 搜检流程

**入场搜检**（极严）：

1. **脱鞋**——检查鞋底是否藏物
2. **解发**——解开头发检查
3. **搜身**——全身抚摸检查
4. **查行李**——打开包裹检查

**违禁物品**：
- 自带墨砚（考场统一发墨）
- 食物
- 书籍
- 纸条
- 任何可能作弊的物品

### 3.2 号舍结构

- **尺寸**：约1米宽、1.5米深，可坐可卧
- **设施**：前面有木板可当桌子，后面有板可当椅子
- **编号**：按入场顺序分配，不按省份
- **环境**：独立空间，采光有限，通风较差

### 3.3 考场纪律

- **点名入场**：寅时开始，按批次进入
- **领卷**：进入号舍后，领取试题
- **答题**：子时（23:00-1:00）发题，天亮开始写
- **交卷**：第三天傍晚前必须交卷
- **出场**：经检查无夹带后放行

## 四、主考官

### 4.1 选派

| 项目 | 说明 |
|------|------|
| **任命** | 皇帝钦点，从京官中选派 |
| **人数** | 每省一正一副（顺天乡试可多至四员） |
| **职责** | 阅卷、评定去取、核定名次 |
| **入闱** | 八月初六日入贡院，入帘后不得外出 |

### 4.2 巡场规则

- 主考官会亲自巡场，检查考场秩序
- 巡场时可在考生身边停留，查看答题情况
- 发现违规可当场取消考试资格

### 4.3 历史人物：刘墉

**刘墉（1719-1804）**：
- 字崇如，号石庵
- 乾隆朝名臣，刘统勋之子
- 历任湖南学政、内阁学士、礼部尚书等
- **"科场青天"**——任湖南学政时，揪出替考枪手17人，革除6个生员功名
- 以严格公正著称，是考生们既敬又畏的主考官

## 五、考试内容（乾隆朝定制）

### 5.1 三场考试

| 场次 | 日期 | 考试内容 |
|------|------|----------|
| **第一场** | 八月初九 | 四书义三篇、五言八韵诗一首 |
| **第二场** | 八月十二 | 经文五篇 |
| **第三场** | 八月十五 | 策问五道 |

### 5.2 题型详解

**四书义**：
- 从《论语》《中庸》《大学》《孟子》中出题
- 每篇200字以上
- 八股文格式：破题、承题、起讲、入手、中股、后股、束股

**五言八韵诗**：
- 题目由考场提供
- 五言律诗，押平声韵
- 限用指定韵部

**经文**：
- 从《诗经》《尚书》《礼记》《周易》《春秋》中任选一经
- 每篇300字以上

**策问**：
- 结合经史、时务、政治出题
- 考生需提出对策建议

### 5.3 试题示例

**四书义题目**（历史真实）：
- "不以规矩，不能成方圆"
- "大学之道，在明明德"
- "君子喻于义，小人喻于利"

## 六、考生入场携带物品

### 6.1 允许携带

| 物品 | 说明 |
|------|------|
| 考场统一发放的墨 | 考生不得自带墨砚 |
| 蜡烛 | 限数量，由考场提供或自带 |
| 简单衣物 | 无花纹、无夹层 |
| 笔墨 | 毛笔、纸张由考场提供 |
| 食物 | 少量干粮（需检查） |

### 6.2 禁止携带

- 自带墨砚
- 书籍
- 纸条
- 任何可能被认为作弊的物品

## 七、录取与放榜

### 7.1 录取

| 项目 | 说明 |
|------|------|
| **录取名称** | 举人（乙榜出身） |
| **第一名称** | 解元 |
| **第二名称** | 亚元 |
| **第三至五名** | 经魁 |
| **第六名** | 亚魁 |
| **五名之后** | 举人（无特定称呼） |

### 7.2 放榜

- **时间**：大约在八月中下旬
- **日期**：多在寅日或辰日
- **别称**：因属龙虎称"龙虎榜"；因桂花盛开称"桂榜"
- **地点**：贡院外墙张贴

### 7.3 举人特权

- 可参加次年春季会试
- 可经吏部考选，担任府学、州学、县学学官
- 取得做官资格

---

## 八、旗人考生特殊规则

### 8.1 旗人乡试

- 旗人可参加乡试，但有单独录取名额
- 旗人考生试卷有特殊标记（"满"字号、"合"字号等）
- 旗人学政在阅卷时可能偏袒旗人考生（历史事实）

### 8.2 本小说中的体现

- 沈砚之在岁考中被旗人考生压至二等第一
- 乡试中佟世安与沈砚之同场，旗人身份可能带来不公平优势

## 九、适合本章（第31章）的细节

### 9.1 沈砚之视角

| 细节 | 小说中的应用 |
|------|--------------|
| 寅时点名入场 | 沈砚之凌晨在贡院外排队 |
| 搜检严格 | 兵丁对沈砚之的检查：脱鞋、解发、搜身 |
| 自带墨砚被扣 | 沈砚之的墨砚被扣下 |
| 刘墉巡场 | 刘墉在考场内巡场，在沈砚之身边停留 |
| 号舍独立 | 沈砚之在号舍内答题 |
| 试题"不以规矩，不能成方圆" | 沈砚之破题 |

### 9.2 考场氛围

- 考生噤声，不敢喧哗
- 刘墉"科场青天"之名让有背景的考生都紧张
- 旗人考生有特殊标记
