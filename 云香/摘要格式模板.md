# 天香 · 章节摘要格式模板（V2 含六要素）

> 统一全书280章摘要格式，强制要求六要素全部加双链。配套工具：`auto_wikilink.py`

## 模板结构

```markdown
# 第X章 [章节名] 摘要

## 六要素
- **时间**：[[乾隆三十六年]][[八月十二]][[未时]]
- **地点**：[[江宁]][[贡院]]、[[鸡鸣寺]]
- **人物**：[[沈砚之]]、[[苏锦婳]]、[[石青]]
- **起因**：[[恩科乡试]]第三场收卷
- **经过**：出龙门后汇合；翌日游[[鸡鸣寺]]偶遇[[婉姓女子]]
- **结果**：[[刘墉]]力排众议取中[[沈砚之]]卷子

## 核心情节
段落1：事件1简要描述（1-2句话）
段落2：事件2简要描述（1-2句话）
段落3：事件3简要描述（1-2句话）

## 重要转折点
- 转折1：发生了什么+意味着什么
- 转折2：发生了什么+意味着什么（≤3条）

## 暗线伏笔
- 伏笔1：线索+预计回收阶段
- 伏笔2：暗线+当前状态

---

**主要人物**：[[人物A]] [[人物B]] [[人物C]]（≤8人）
**核心情节**：单段浓缩，100-150字，分号分隔
**重要转折**：转折1；转折2；转折3
（本章字数：约XXXX字）
```

## 六要素细则

时间/地点/人物：所有出现的关键词加双链
起因：触发条件，1-2句话
经过：按时间线分段，每段1-2句
结果：直接结果或状态变化

## 双链规范

| 类型 | 示例 | 不加链 |
|------|------|--------|
| 人物 | [[沈砚之]] | 代词、称谓 |
| 地点 | [[苏州]]、[[贡院]] | 泛称 |
| 时间 | [[乾隆三十六年]] | 模糊时间 |
| 事件/制度 | [[恩科乡试]] | 无 |
| 官职 | [[知县]]、[[知府]] | 泛称 |
| 技术/物品 | [[天香纱]] | 普通物品 |

## 调用方式

生成摘要：
> "请按摘要格式模板 V2 规范，为第X章提取摘要，含六要素，关键词加双链。"

自动补链：
```bash
python auto_wikilink.py 已发布摘要/第X章.md
python auto_wikilink.py --dry-run 已发布摘要/第X章.md  # 预览
```
