# 天香 · 章节摘要格式模板（V2 含六要素）

> 本模板用于统一全书280章的摘要格式，并强制要求时间、地点、人物、起因、经过、结果六要素全部加双链。
> 配套工具：`auto_wikilink.py`（自动为摘要补全双链）

---

## 模板结构

```markdown
# 第X章 [章节名] 摘要

## 六要素

- **时间**：[[乾隆三十六年]][[八月十二]][[未时]]
- **地点**：[[江宁]][[贡院]]、[[鸡鸣寺]]、[[锦云丝局]]
- **人物**：[[沈砚之]]、[[苏锦婳]]、[[石青]]、[[刘墉]]
- **起因**：[[恩科乡试]]第三场收卷，[[沈砚之]]完成五道策问
- **经过**：出龙门后与同年汇合；翌日游[[鸡鸣寺]]偶遇[[婉姓女子]]；[[沈明之]]向[[苏锦婳]]借银被拒
- **结果**：[[刘墉]]力排众议取中[[沈砚之]]卷子；[[石青]]正式护卫现身

## 核心情节

段落1：事件1的简要描述（1-2句话）

段落2：事件2的简要描述（1-2句话）

段落3：事件3的简要描述（1-2句话）

## 重要转折点

- 转折点1：具体发生了什么，意味着什么
- 转折点2：具体发生了什么，意味着什么
- 转折点3：具体发生了什么，意味着什么（控制在3条以内）

## 暗线伏笔

- 伏笔1：本章埋下的什么线索，预计在哪一阶段回收（如：[[婉姓女子]]丝巾绣"婉"字——[[舒婉]]早期埋设，预计[[山东]]任上正式回收）
- 伏笔2：本章延续的什么暗线，当前处于什么状态（如：[[沈砚之]]"不当私于一族一姓"——满汉矛盾立场初现，预计[[齐河]]知县阶段被政敌攻击）
- 伏笔3：本章的什么细节暗示了后续走向（如：[[石青]]护卫现身——武力保护体系建立，预计后续对抗[[麻六]]、[[富察瑞麟]]时启用）

---

**主要人物**：[[人物A]] [[人物B]] [[人物C]]（仅列出核心人物，不超过8人）

**核心情节**：单段浓缩总结，涵盖本章所有核心事件线，用分号或句号分隔。（100-150字）

**重要转折**：转折1；转折2；转折3。（用分号分隔，单句概括）

（本章字数：约XXXX字）
```

## 六要素细则

### 1. 时间
- 所有出现的时间点都要加双链
- 包括：年号（[[乾隆三十六年]]）、月份（[[八月]]）、日期（[[八月十二]]）、时辰（[[未时]]）
- 如果本章跨越多日，列出主要时间点

### 2. 地点
- 所有出现的地点都要加双链
- 包括：城市（[[苏州]]、[[江宁]]）、建筑（[[贡院]]、[[鸡鸣寺]]）、机构（[[锦云丝局]]、[[永顺丝行]]）
- 如果同一地点多次出现，只列一次

### 3. 人物
- 所有出场人物都要加双链
- 包括：主角、配角、只提及名字但未出场的人物
- 六要素区块中列出本章核心人物即可

### 4. 起因
- 本章事件的触发条件
- 用1-2句话概括，关键词加双链

### 5. 经过
- 本章的主要事件流程
- 按时间或空间线分段，每段1-2句话
- 所有关键词加双链

### 6. 结果
- 本章事件的直接结果或状态变化
- 用1-2句话概括，关键词加双链

## 格式细则

### 标题
- 格式：`# 第X章 [章节名] 摘要`
- 如果原文没有明确章节名，则使用 `# 第X章 摘要`

### 六要素区块
- 必须放在标题之后、核心情节之前
- 使用条目式（`-`），每项一行
- **所有关键词必须加双链**，不加双链视为格式不合格

### 核心情节
- 分段叙述，每段 1-3 句话
- 按时间线或空间线（如苏州线/江宁线）分段
- 语言精炼，只保留关键动作和结果

### 重要转折点
- 使用条目式（`-` 或 `*`）
- 每条 1 句话，说明"发生了什么"+"意味着什么"
- 严格控制数量：**不超过3条**

### 分隔线
- 正文结束后必须插入 `---`

### 底部浓缩总结
- **主要人物**：列出核心人物，用空格分隔，不加括号注释
- **核心情节**：单段浓缩，100-150字
- **重要转折**：单句概括，用分号分隔
- **本章字数**：`（本章字数：约XXXX字）`

## 双链规范

### 必须加双链的关键词类型

| 类型 | 示例 | 不加链的例外 |
|------|------|-------------|
| 人物 | [[沈砚之]]、[[苏锦婳]] | 代词（他、她）、称谓（爹、娘） |
| 地点 | [[苏州]]、[[贡院]]、[[鸡鸣寺]] | 泛称（镇上、院里） |
| 时间 | [[乾隆三十六年]]、[[八月十二]] | 模糊时间（不久、后来） |
| 事件/制度 | [[恩科乡试]]、[[岁考]]、[[归公中]] | 无 |
| 官职 | [[知县]]、[[知府]]、[[军机大臣]] | 泛称（官员、上级） |
| 技术/物品 | [[天香纱]]、[[蚕种]]、[[缫丝]] | 普通物品（桌子、椅子） |

### 双链添加方式

**方式一：生成摘要时手动加链**
- 在核心情节中直接写 `[[沈砚之]]在[[贡院]]外排队`

**方式二：用 auto_wikilink.py 自动补链**
- 先按模板写出摘要（可以暂不加链）
- 运行 `python auto_wikilink.py 已发布摘要/第X章.md`
- 脚本自动扫描词库，为所有匹配词加上 `[[ ]]`
- **注意**：脚本不会加六要素区块，只会在正文中自动补链

## 词库维护

词库位置：`云香/双链词库/`

| 文件 | 内容 | 维护方式 |
|------|------|---------|
| `人物.txt` | 所有出场人物名 | 新增人物卡时追加 |
| `地点.txt` | 城市、建筑、机构 | 出现新地点时追加 |
| `事件.txt` | 制度、事件、技术、物品 | 出现新概念时追加 |
| `时间.txt` | 年号、年月日、时辰 | 固定，基本不变 |
| `官职.txt` | 官职、科举等级 | 出现新官职时追加 |

**维护原则**：
- 新增人物/地点/概念时，立即追加到对应词库
- 一个词不要重复出现在多个词库文件中（脚本会自动去重）
- 人物名以人物卡文件名为准（如 `索绰络鄂善.md` → 词库写 `索绰络鄂善`）

## 常见错误

| 错误类型 | 错误示例 | 正确做法 |
|---------|---------|---------|
| 缺少六要素区块 | 直接写核心情节 | 必须先写六要素 |
| 六要素未加双链 | 时间：八月十二 | 时间：[[八月十二]] |
| 核心情节过长 | 超过200字 | 控制在100-150字 |
| 重要转折点过多 | 列出5-6条 | 严格限制3条以内 |
| 段落过长 | 一段超过5句话 | 每段1-3句话 |
| 遗漏分隔线 | 正文直接接底部 | 必须插入 `---` |
| 无字数标注 | 结尾无字数 | 必须标注 `(本章字数：约XXXX字)` |

## 工具说明

### auto_wikilink.py

- **功能**：读取词库，为 Markdown 文件中的关键词自动添加 Obsidian 双链 `[[ ]]`
- **去重保护**：不会重复添加已有双链
- **排序保护**：按词长度降序匹配，避免"沈砚"覆盖"沈砚之"
- **范围保护**：不修改已有 `[[ ]]` 内部、代码块、URL 中的文本
- **输出**：直接覆盖原文件，或输出到新文件
